Commit before ACK

A majority of replicas holds the message before the sender sees a tick. So a tick is a promise.

CDC, no outbox table

An outbox exists to give consumers a clean event. Here the append-only row already is that event.

In SD-08 the posts table is mutable, so it needs an outbox. Here the log is the table.

Chat · send pathstage 4
Send path · code 1 of 2 · the partition leader

Dedup first, so a retry never burns a number

def on_send(frame):
    key = (frame.conv_id, frame.client_msg_id)
    # a retry of something still committing? attach to that entry
    if key in in_flight:
        return in_flight[key].then(ack)
    # the same clientMsgId, already committed? return the original
    seen = client_msgs.get(key)
    if seen:
        return ack(frame, seen.seq)
    # only the leader assigns; a stale leader is fenced by term
    seq = last_seq[frame.conv_id] = last_seq[frame.conv_id] + 1
    # message and dedup row: one Raft entry, so both or neither
    in_flight[key] = raft.propose(message(frame, seq), dedup_row(frame, seq))
    # a majority has it: only now is the tick true
    return in_flight[key].then(ack)

Send path · code 2 of 2 · the delivery worker

Hand off to gateways; delivery is best-effort on purpose

def on_message_stored(event):
    members = cached_members(event.conv_id)
    sessions = registry.multi_get(members)

    # every device online gets a push, including the sender's others
    for gateway, devices in by_gateway(sessions, skip=event.sender_device):
        gateway.push_async(devices, event, deadline_ms=200)

    # offline users get a wake-up; large groups collapse them
    for user in offline(members, sessions):
        push_platform.notify(user, event, collapse=(event.tier == LARGE))

    # a failed push is fine: the log has it, the device will ask
    kafka.commit(event.offset)

What changed, then the difference

def on_sync(device, frame):
    # the gateway registered this session before we got here
    changed = inbox.changed_since(device.user, frame.last_sync_ts)

    for conv in newest_first(changed):
        after = frame.cursors.get(conv, member_join_seq(conv, device.user))
        page = messages.read(conv, after=after, limit=frame.limit_per_conv)
        device.send(page, has_more=page.has_more)
        # admission control: cap each device's burst
        if device.burst_exhausted():
            return retry_later(device)

    device.send(LIVE)
Chat · sync servicestage 4
Sync path · code 2 of 2 · on the device

Upsert by seq, check the gap, never get stuck

def on_msg(msg):
    cursor = local_cursor[msg.conv_id]
    # seen it before? this is a no-op
    if msg.seq <= cursor:
        return
    local_db.upsert((msg.conv_id, msg.seq), msg)
    if msg.seq > cursor + 1:
        # hold it back; fetch what is missing
        send(SYNC, {msg.conv_id: cursor})
        return
    # unknown kinds still advance the cursor: never get stuck
    if msg.kind in KNOWN_KINDS:
        apply_and_render(msg)
    local_cursor[msg.conv_id] = msg.seq
    send(DELIVERED, msg.conv_id, msg.seq)
