Theory · what it is

A fast proximity index next to an exact assignment

It is

Assigning scarce, moving resources to requests, exactly once, from an approximate picture of where they are.

Not a map search

“Restaurants near me” never runs out; a driver can be given away only once.

Not routing

Routing says how long; matching says who. Matching calls routing.

Not fleet telemetry

Telemetry keeps history; matching needs only the latest four seconds.

Claims pause
