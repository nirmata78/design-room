API · two different jobs

Idempotency protects the request. Dedup protects the user.

Idempotency

The same request twice, after a timeout.

Same dedupKey → same id back.

Dedup

Two requests that mean the same thing.

Second one → SUPPRESSED.

Make the dedupKey mandatory: both become a contract, not a hope.
