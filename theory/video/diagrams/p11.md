# Part 11 · diagram specifications

Ten figures, three sessions (four, three, three). Rules: `diagrams/README.md`.

## p11-dns-anycast
- **Kind:** three stacked rows, canvas 1600 × 820, titles "DNS", "Geo DNS", "Anycast".
- Row 1: `client` → `resolver (caches for TTL)` → `authoritative DNS` → "203.0.113.10".
- Row 2: two resolvers `resolver EU`, `resolver US` getting different answers "EU site" / "US site".
- Row 3: three sites `EU`, `US`, `Asia` all announcing "198.51.100.1" (BGP arrows); a client's
  packet routed to the nearest; the EU site crossed out with "withdraw route → traffic moves in
  seconds" (**highlight**).

## p11-l4-l7
- **Kind:** two panels, canvas 1600 × 700, titles "Layer 4: per connection" and "Layer 7: per request".
- Left: two thick client connections; each goes whole to one backend; one backend bar red "all
  requests of a long gRPC connection".
- Right: the same connections terminated at an `L7 proxy`; individual request arrows spread evenly
  across four backends.

## p11-health
- **Kind:** block diagram, canvas 1600 × 760.
- `Load balancer` with probe arrows to five backends: three green, one red "fails probes → ejected",
  one amber "errors 5× peers → outlier ejected".
- A sixth backend with a drain sequence beside it: "① readiness fails ② no new requests ③ finish
  in-flight ④ exit".
- Bottom box (**highlight**): "panic threshold: if > 50% look unhealthy, send to all".

## p11-gateway-bloat
- **Kind:** three gateway boxes growing in size, canvas 1600 × 640, labelled "year 1", "year 2",
  "year 3". Contents: year 1 "TLS · auth · routing"; year 2 adds "transform for client X"; year 3 adds
  "orchestrate A + B" (red). Beside year 3, many team icons queued "every change needs a gateway
  deploy" (**highlight**).

## p11-orphan-work
- **Kind:** timeline, canvas 1600 × 700. Lanes `Front end`, `A`, `B`, `C`.
- Front end bar 0 to 1.0 s, ending with "timeout → error to user" at 1.0 s.
- A bar 0.05 to 5 s, B bar 0.1 to 5 s, C bar 0.2 to 5 s (grey hatched from 1.0 s onward,
  **highlight**: "orphan work: nobody will read the answer").

## p11-deadline
- **Kind:** Seq, canvas 1600 × 720. Participants `Front end`, `A`, `B`, `C`.
- 1. FE → A "deadline = now + 800 ms". 2. A → B "deadline same · 750 ms left". 3. B → C "670 ms
  left". 4. C → B "result (300 ms)". 5. alternative: FE → A "cancel" dashed red, propagating to B
  and C (**highlight**) "every hop stops".

## p11-offset

  of the underlying list (green).

## p11-conn-tier
- **Kind:** block diagram, canvas 1600 × 760.
- Clients (phones, laptops) with long arrows to `gateway 1 … gateway 7 … gateway 30`.
- `gateway 7` → `Routing table` "user 42 → gw 7 (lease, heartbeat)".
- Services → `Dispatcher` → lookup routing table → `gateway 7` → user 42's connection
  (**highlight**).
- A note on one gateway crossed out: "dies → 500k reconnect · jittered over 30 s".

## p11-resumable
- **Kind:** Seq, canvas 1600 × 720. Participants `Client`, `Upload service`.
- 1. "start session → session URL". 2. "chunk 0–8 MB" ✓. 3. "chunk 8–16 MB" ✓ … 4. a chunk with a
  red cross "connection drops". 5. "how much do you have?" → "bytes 0–419,430,399" (**highlight**).
  6. "resume from 419,430,400". 7. "final chunk · checksum" → "object complete".

## p11-trie
- **Kind:** tree, canvas 1600 × 720.
- Root `/` → `api` (value: route A) → `v1` (value: route B) → children `orders` (value: route C),
  `payments` (value: route D).
- Query path "/api/v1/users" drawn red down to `v1`, then a dashed dead end "no 'users' child"
  (**highlight**), result "longest match: /api/v1 → route B".
